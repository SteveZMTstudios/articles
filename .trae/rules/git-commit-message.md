严格遵守以下命令式规范，撰写符合标准的 Git 提交信息：

· 用空行分隔标题、正文和脚注。
· 将标题长度限制在 50 个字符以内。
· 标题首字母不要大写。
· 标题末尾切勿添加句号。
· 以祈使语气书写标题，例如“修复错误”而非“修复了错误”或“错误已修复”。
· 控制正文每行长度不超过 72 个字符。
· 在正文中解释变更的动机、原因和上下文，而非罗列代码实现。
· 统一采用 <类型>[可选作用域]: <描述> 格式，类型如 feat、fix、docs、style、refactor、test、chore 等。
· 若使用脚注，引用关联议题时使用 Refs #编号 或 Closes #编号。
